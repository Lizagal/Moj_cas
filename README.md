# Kam izgine moj čas? – Mojih 24 ur

Samostojna statična spletna aplikacija za razredno uro. Ne potrebuje knjižnic, strežnika ali prijave.

## Objava
1. Na GitHubu ustvarite nov javni repozitorij `mojih-24-ur`.
2. Naložite `index.html` in `README.md` v koren repozitorija (Add file → Upload files → Commit changes).
3. Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save.
4. Ko je objava končana, odprite povezavo, ki jo izpiše GitHub Pages. Preverite jo na telefonu in jo delite z dijaki.

## Izvedba (45 minut)
5 min uvodna samoocena; 10 min razporeditev dneva; 5 min telefon; 5 min projekcije; 5 min navade; 5 min osebni cilj; 10 min razprava.

Vprašanja za razpravo: Kaj vas je presenetilo? Kdaj je uporaba tehnologije koristna? Kako bi prerazporedili 30 minut? Kako preprečiti dvojno štetje dejavnosti? Kaj lahko preverimo čez sedem dni?

## Zasebnost in zbiranje
Odgovori so le v pomnilniku odprte strani in se ob osvežitvi izgubijo. Aplikacija jih ne pošilja na strežnik. Dijaki lahko izvozijo osebno poročilo ali ga natisnejo v PDF. Oddaja naj bo prostovoljna. Za anonimno skupinsko analizo pripravite ločen Forms z neobveznimi številčnimi vprašanji (spanje, učenje, digitalna zabava, ocena in dejanska uporaba telefona). Izključite beleženje imen in preverite nastavitve dostopa. Ne zbirajte osebnih poročil za javni prikaz. GitHub kot gostitelj lahko obdeluje običajne tehnične podatke obiska.

Čez sedem dni naj dijaki ponovijo meritev in zase primerjajo rezultate. Vprašalnik ni standardiziran psihološki instrument.
